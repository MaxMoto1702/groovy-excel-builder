[[sheet]]
== Sheets

You can create any number of sheets and configure sheet-level options.

[source,kotlin]
----
val workbook = ExcelBuilder().build {
    sheet {
    }
}
----

=== Sheet Name

[source,kotlin]
----
val workbook = ExcelBuilder().build {
    sheet(name = "My Sheet") {
    }
}
----

=== Column Widths

[source,kotlin]
----
val workbook = ExcelBuilder().build {
    sheet(widthColumns = listOf(10, 20, 30)) {
    }
    sheet(widthColumns = listOf("default", 20, 30)) {
        // first column keeps the default width
    }
}
----

NOTE: Use the special value `"default"` to keep the default column width.
