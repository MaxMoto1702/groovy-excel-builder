== Getting Started

=== Dependency

[source,kotlin,subs=attributes+]
.Gradle (Kotlin DSL)
----
dependencies {
    implementation("{groupId}:{artifactId}:{version}")
}
----

Or download
http://repo.serebryanskiy.site/{groupId}/{artifactId}/{version}/{artifactId}-{version}.jar[library]
and add to your project.

=== Your First Excel Document

[source,kotlin]
----
val workbook = ExcelBuilder().build {
    sheet {
        row {
            cell { "test" }
        }
    }
}

FileOutputStream("sample.xlsx").use { workbook.write(it) }
----

=== Dynamic Data

[source,kotlin]
----
val workbook = ExcelBuilder().build {
    sheet {
        (1..6).forEach { number ->
            row {
                ('A'..'F').forEach { letter ->
                    cell { "$number $letter" }
                }
            }
        }
    }
}
----

NOTE: This builder supports XLSX documents (SXSSFWorkbook streaming workbook).
