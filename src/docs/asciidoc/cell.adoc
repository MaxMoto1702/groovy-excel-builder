[[Cell]]
== Cells

=== Cell Values

Supported value types:

* String
* Calendar
* Date
* Number
* Boolean

=== Creating Cells

[source,kotlin]
----
val workbook = ExcelBuilder().build {
    sheet {
        row {
            cell { }
            cell()
            cell { "Text" }
        }
    }
}
----

=== Skipping Cells

[source,kotlin]
----
val workbook = ExcelBuilder().build {
    sheet {
        row {
            cell { "A" }
            skipCell()
            cell { "B" }
            skipCell(2)
            cell { "C" }
        }
    }
}
----

=== Spans

[source,kotlin]
----
val workbook = ExcelBuilder().build {
    sheet {
        row {
            cell(rowspan = 2) { "This cell takes two rows" }
            cell(colspan = 2) { "This cell takes two columns" }
        }
    }
}
----

NOTE: Overlapping merged regions are invalid in Excel and may be removed by the editor.

=== Styles

[source,kotlin]
----
val workbook = ExcelBuilder().build {
    sheet {
        row {
            cell(style = "cell-style") { "Styled" }
        }
    }
}
----

NOTE: Cell-level style overrides row-level style.
