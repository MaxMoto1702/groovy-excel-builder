[[introduction]]
== Introduction

This module exposes a Kotlin DSL to create Excel XLSX documents using
https://poi.apache.org/[Apache POI].

The goal is to keep common spreadsheet scenarios simple while still giving
access to POI styles, fonts, formats, row/column sizing, and merge regions.

If you encounter any issues or inconsistencies while using this library,
please https://github.com/MaxMoto1702/groovy-excel-builder/issues[create an issue].
